## Color science references

The color-matching implementation uses standard sRGB/D65 conversions and the CIEDE2000 formula.

- [W3C CSS Color 4: color difference formulas](https://www.w3.org/TR/css-color-4/#color-difference)
- Sharma, Wu, and Dalal, *The CIEDE2000 Color-Difference Formula: Implementation Notes, Supplementary Test Data, and Mathematical Observations* (2005). [Author's reference data](https://hajim.rochester.edu/ece/sites/gsharma/ciede2000/dataNprograms/ciede2000testdata.txt).

Tests use numerical reference pairs to verify the implementation.
